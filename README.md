# Portfolio Paul Fourton

Site portfolio statique pret pour GitHub Pages.

## Publication GitHub Pages

1. Creer un depot GitHub public nomme `portfolio-paul-fourton`.
2. Envoyer ce dossier sur la branche `main`.
3. Dans GitHub, aller dans Settings > Pages.
4. Choisir `Deploy from a branch`, branche `main`, dossier `/root`.

L'URL sera ensuite du type:

`https://votre-pseudo.github.io/portfolio-paul-fourton/`
